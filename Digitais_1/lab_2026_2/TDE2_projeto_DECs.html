Objetivo

A ideia é usar os conhecimentos adquiridos em Circuitos Combinais (Eletrônica Digital Combinacional) para projetar e realizar DEC’s para Displays de 7-Segmentos, capazes de mostrar mensagens, principalmente, se cada projeto for adequadamente disposto ao lado de outro.

Para realizar este circuito o projetista pode fazer uso de:

  • Mapas de Karnaugh (Permitido uso do Logisim-evolution para facilitar obtenção dos Mapas de Karnaugh: opções: 1) Projeto > Analisar Circuito > Entradas e Saídas,  2) Projeto > Analisar Circuito > Tabela Verdade e 3) Projeto > Analisar Circuito > Minimizada. Notar que o mesmo permite-se o uso de condições “don’t care”. Efeito colateral: maior quantidade de pastilhas?)

  • Multiplexadores

    (Efeito colateral: Implica uso de 1 pastilha para cada variável de saída).

  • Decodificador

    (1 x DEC 4/10 + portas AND/NAND de largura variável para cada variável de saída).

  • Pastilhas AOI (Efeito colateral: uma pastilha para cada variável de saída à ser sintetizada).

     

O que importa é buscar uma redução drástica no número de pastilhas necessárias para completar um projeto.

Observações

  • Estão previstos 10 projetos, um para cada equipe. Cada um é diferente do outro. Cada equipe é responsável pelo seu projeto.
  • Cada equipe é formada por 2 alunos (no máximo 3, sob autorização prévia do professor).
  • Cada equipe deve providenciar e identificar claramente os bits de entrada do seu circuito, seguindo o padrão BCD, no qual A=bit LSB e D=bit MSB.
  • Note que 16 combinações de código de entrada são possíveis, mas apenas 10 (sequencia decimal, código BCD) são usados. O que significa que sim, podem ser explorado o uso de condições “don´t care” no projeto. Cabe ao projetista escolher e deixar documentado como seu circuito (sua solução) vai lidar com códigos não-BCD. No caso da solução usando Mapas de Karnaugh, se for optado pelo uso de condições “don’t care”, o projetista deve acrescentar deduções e uma tabela mostrando como ficaria a saída do display para códigos não-BCD.

Itens/Seções do Relatório

O Relatório deve conter os seguintes itens:

  1. O problema: apresente o seu problema. No que consiste o seu projeto. Não apresente a tabela completa mostrada na figura acima, mas deixe claro o Número do seu projeto. Você pode apresentar a tabela geral mostrada no início desta página apenas se for para contextualizar que o seu projeto é parte de um projeto maior, mas o texto deve voltar a atenção para o seu projeto.

  2. Tabela Verdade do DEC: apresente a Tabela verdade completa do seu DEC, incluindo todas as 16 combinações binárias de entrada. Deixe claro como serão tratados (ou não) os códigos não-BCD. Estará sendo previsto como o display deve se comportar para códigos não-BCD!?

    Deixar claramente indicado, o tipo de display de 7-segmentos que será usado. Se é o de Cátodo comum, cujo pino comum é ligado no GND e seus segmentos trabalham na configuração “ativo alto” (a=…).  Ou se será usado display de Ãnodo Comum, com pino comum ligado ao +Vcc e onde os segmentos trabalham na configuração “ativo baixo” (a―=…).

    Note que os 2 displays são esteticamente semelhantes, o que difere é seu código do vendedor (SKU = Stock Keeping Unit, Unidade de Manutenção de Estoque) ou Part Number (código do fabricante), e forma de alimentação.

    Lembrar que todos os displays de 7-segmentos exigem resistores para reduzir a d.d.p. aplicada sobre seus leds.

  3. Resolução: a) apresente os Mapas de Karnaugh, agrupamentos realizados e equações derivadas dos mapas/agrupamentos ou b) apresente a forma como pretende “programar” as entradas de cada MUX (deixar claro o tamanho do(s) MUX(es) adotados) ou c) deduzir/mostrar as equações que justificam a porta lógia básica usada na saída de um DEC 4/10 ou DEC 4/16. Usando a opção (a) você pode ainda fazer uso de pastillhas AOI. Você é livre para escolher a sua forma de solução: (a), (b) ou (c). Pode até misturar diferentes abordagens no mesmo projeto.

  4. Otimizações: exponha e explique como otimizou o circuito usando a mesma porta lógica para repetir os mesmos segmentos de expressões booleanas (expressões boolenas parciais compartilhadas por mais de uma variável de saída) ou (se foi o caso), porque resolveu usar apenas portas NAND ou apenas NOR para sintetizar uma ou outra saída ou porque resolveu usar um circuito do tipo AOI. Enfim, deixe claro que estratégia(s) usou para minimizar a quantidade de pastilhas necessárias para implementar (realizar) a sua solução.

    Por exemplo, suponha que a equação inicial para o segmento a tenha gerado a expressão: a=…+DC―B+… e que o segmento d contenha a mesma expressão booleana parcial: d=…+AC―B+…. Note que o segmento de expressão lógica C―B não deveria ser montado/realizado 2 vezes. A parte deste circuito associado com esta expressão (AND(2)) seria executada/montada apenas 1 única vez e compartilhada tanto pelos circuitos do segmento a quando segmento d ou mais se for o caso.

    Contabilidade rápida: considere que, como todo o circuito implica 7 circuitos de saída (um para cada segmento), eventualmente poderiam ser usadas 7 pastilhas AOI + 1 única pastilha do tipo 74LS04 (6 portas inversoras) para sintetizar todo o circuito, o que contabiliza um uso final de 8 pastilhas. Então são esperados circuitos usando menos de 8 pastilhas (o que já é algo “grande”).

Últimas notas

Podem ser usadas pastilhas “AOI” que são pastilhas (CIs) que integram diferentes combinações de portas lógicas básicas And-Or-Inverter, dai o seu nome, AOI.

Por exemplo, a figura à seguir mostra a pastilha 74LS54.

Esta pastilha traz portas And-Or-Inverter na configuração 4-wide 2-input 3-input AOI gates, que internamente realiza a seguinte função lógica:

Y=AB+CDE+FG+HJK―

Existem outras pastilhas AOI:

  • 74LS51 (2-wide 2-input 2-wide 3-input AOI gates) e,
  • 74LS55 (2-wide 4-input AOI gates).
