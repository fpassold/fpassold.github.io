TDE2: Projeto DEC/Display Especial

Objetivo: a idéia é usar os conhecimentos adquiridos em Circuitos Combinais (Eletrônica Digital Combinacional) para projetar e realizar DEC’s para Displays de 7-Segmentos, capazes de mostrar mensagens, principalmente, se cada projeto for adequadamente organizado ao lado de outro.

Para realizar este circuito o projetista pode fazer uso de Mapas de Karnaugh (uso das opções: Projeto > Analisar Circuito > Entradas e Saídas, Projeto > Analisar Circuito > Tabela Verdade e Projeto > Analisar Circuito > Minimizada, do Logisim-evolution), multiplexadores, decodificadores ou pastilhas AOI para sintetizar o circuito. O que importa é buscar uma redução drástica no número de pastilhas necessárias para completar cada circuito.

DEC’s de 2026/2

Acompanhe pela figura abaixo:

Cada coluna na tabela acima, destaca um projeto específico (diferente dos outros), o que implica na criação de um DEC específico para cada coluna, capaz de gerar a sequência de caracteres para determinado código BCD de entrada (linhas 0000(2)=0(10) até 1001(2)=9(10)).

Isto significa que cada coluna de 1 até 10 corresponde a um projeto/equipe, responsável pelo mesmo.

São então 10 projetos. A idéia é que se os 10 projetos forem realizados, um outro circuito (providenciado pelo professor), gerará o código de entrada, de 0000(2)=0(10) até 1001(2)=9(10), o que vai fazer com que cada projeto apresente o seu caracterer especídifo para o código de entrada e se os projetos/proto-boards forem arranjados lado a lada e sequencialmente da forma mostrada na tabela anterior, para cada novo código de entrada vai surgir uma “frase” nos 10 displays.

Por exemplo, para o códifo de entrada Input=4(10)=0100(2), se cada projeto for colocado lado a lado como prevê a tabela anterior, nos diplays deve surgir a mensagem “SoLar oPen”.

Observações:

  • Estão previstos 10 projetos, um para cada equipe. Cada um é diferente do outro.

  • Cada equipe é formada por 2 alunos (no máximo 3, sob autorização prévia do professor).

  • Cada equipe deve providenciar e identificar claramente os bits de entrada do seu circuito, seguinto o padrão BCD, no qual A= bit LSB e D= bits MSB.

  • Note que 16 combinações de código de entrada são possíveis, mas apenas 10 (sequencial decilam, cósigo BCD) são usados. O que significa que sim, podem ocorrer casos de “don´t care”.

Itens/Seções do Relatório

O Relatório deve conter os seguintes itens:

  1. O problema: apresente o seu problema. No que consiste o seu projeto. Não apresente a tabela completa mostrada na figura acima, mas deixa claro o Número do seu projeto. Você pode apresentar a tabela geral mostrada no início desta página apenas se for para explicar que o seu projeto é parte de um projeto maior, mas o texto deve voltar a atenção para o seu projeto.
  2. Tabela Verdade do DEC: apresente a Tabela verdade completa do seu DEC, incluindo as 16 combinações binárias de entrada. Deixe claro como serão tratados (ou não ) os códigos “don’t care”. Está sendo previsto como o display deve se comportar para códigos não-BCD!? Deixar claramente indicado, o tipo de display de 7-segmentos que será usado. Se é o de Cátodo comum, cujo pino comum é ligado no GND e seus segmentos trabalham na configuração “ativo alto” (a=…). Ou se será usado display de Ãnodo Comum, com pino comum ligado ao +Vcc e onde os segmentos trabalham na configuração “ativo baixo” (a―=…). Note que os 2 displays são esteticamente semelhantes, o que difere é seu código e forma de alimentação. E todos os displays de 7-segmentos exigem resistores para reduzir a d.d.p. aplicada sobre os leds que compões seus segmentos.
  3. Resolução: a) apresente os Mapas de Karnaugh, agrupamentos realizados e equações derivadas dos mapas/agrupamentos ou b) a forma como pretende “programar” as entradas de cada MUXes (deixa claro o tamanho do(s) MUX(es) adotados ou c) deduza/mostre as equações que explicam a porta usada na saída de um DEC 4/10 ou DEC 4/16. Você é livre para escolher a sua forma de solução, (a), (b) ou (c). Pode até misturar diferentes abordagens. Use (aprenda) a usar um editor de equações para criar um documento técnicamente correto.
  4. Otimizações: exponha e explique como otimizou o circuito usando a mesma porta lógica para repetir os mesmos segmentos de expressões booleanas (expressões boolenas parciais compartilhadas por mais de uma variável de saída) ou (se foi o caso), porque resolveu usar apenas portas NAND ou apenas NOR para sintetizar uma ou outra saída ou porque resolveu usar um circuito do tipo AOI. Enfim, deixe claro que estratégia(s) usou para minimizar a quantidade de pastilhas necessárias para implementar (realizar) a sua solução. Por exemplo, suponha que a equação inicial para o segmento a tenha gerado a expressão: a=…+DC―B+… e que o segmento d contenha a mesma expressão booleana parcial: d=…+AC―B+…. Note que o segmento de expressão lógica C―B não deveria ser montado/realizado 2 vezes. A parte deste cirecuito associado com esta expressão (AND(2)) seria executada/montada apenas 1 única vez e compartilhada tanto pelos circuitos do segmento a quando segmento d ou mais se for o caso. Considere que, como o circuito implica 7 variáveis de saída, eventualmente poderiam ser usadas 7 pastilhas AOI + 1 única pastilha do tipo 74LS04 (6 portas inversoras) para sintetizar todo o circuito, o que contabiliza um uso final de 8 pastilhas. Então são esperados circuitos usando menos de 8 pastilhas (o que já é algo “grande”).
  5. Diagrama Elétrico Final: apresente o diagrama elétrico final do circuito com pastilhas numeradas (U1, U2a, U3c, CI.1, CI.2, etc), com números dos pinos indicados nas pastilhas ou portas lógicas (afinal de contas, você vai montar este circuito), e com o nome dos pinos de entrada (caso das pastilhas MSI, entradas: A0, A1, S1, S0, saída O―1, etc), resistores R1, R2, etc.
  6. Lista de Material (BOM = Bill of Materials): apresente a Lista de Material, relacionando os componentes necessários sendo coerente com a mesma numeração apreesentada no diagrama elétrico. Por exemplo: Parts: R1 à R7 = 330 Ω x 1/8W; R8 = 10 KΩ x 1/8W; D1 = 1N4148; U1, U2, U5 = 74LS32; U3 = 74LS04; C1 = 100 µF x 25V; etc. Note: a lista não explica o que é cada componente. Apenas traz uma relação compatível com a numeração que aparece no diagrama elétrico apresentado.
  7. Fim. Não existe, não se exige nenhum item chamado conclusões. Trata-se de um projeto e não de um estudo. Nâo apresente fotos do projeto ou das partes realizadas. Isto é um relatório técnico não um Documento de Verificação. Guarde as fotos ou vídeos para si mesmo ou exponha na sua rede social, mas não neste relatório.

Últimas notas

Podem ser usadas pastilhas “AOI” que são pastilhas (CIs) que integram diferentes combinações de portas lógicas básicas And-Or-Inverter, dai o seu nome, AOI.

Por exemplo, a figura à seguir mostra a pastilha 74LS54.

Esta pastilha traz portas And-Or-Inverter na configuração 4-wide 2-input 3-input AOI gates, que internamente realiza a seguinte função lógica:

Y=AB+CDE+FG+HJK―

Existem outas pastilhas AOI: 74LS51 (2-wide 2-input 2-wide 3-input AOI gates) e 74LS55 (2-wide 4-input AOI gates).
