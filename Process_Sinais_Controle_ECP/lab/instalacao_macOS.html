brew install libgcrypt glib pixman sdl2 libslirp dfu-util cmake python

  1. Instalando o ESP-IDF usando EIM

Foi preferida a instalação online da GUI, recomendada para a maioria dos usuários. Instala a ESP-IDF e ferramentas via interface gráfica mas exige acesso à internet.

É só rodar o App EIM:

  1. Selecionado: New Instalation > Start Installation.

  2. Selecionado: Easy Installation.

  3. Surge janela com Ready to Install ESP-IDF version: v6.1-beta1 (2.29 GB) !

  4. Preferi selecionar uma versão stable, optando pela: V6.0.2 (2.18 GB), 10-45 minutos ETD em /Users/fernandopassold/.espressif.

  5. Pressionar Start Installation e aguarde. Aparece "Downloading offline package". O processo eim ocupa apenas 1 core da CPU. Depois de uns 8 minutos fazendo download apareceu "Extracting archive: archive_v6.0.2_macos-x64.zst" e Starting offline installation...., Extracting: riscv32 esp elf, tempo estimado: 1m 45s.

  6. Esperando até surgir "Installation Complete!" Com a opção:

    Keep the downloaded package?

    Keeping it lets you reinstall or repair offline later without downloading again.

    /Users/fernandopassold/Library/Application Support/eim/offline_archives/archive_v6.0.2_macos-x64.zst

    Optato por "Keep".

  7. Surge: Next Steps:

    1. Open a new IDF terminal using the icon on version manager screen or by sourcing activation script in any open terminal.
    2. The activation script can be found in ~/.espressif/tools/ folder
    3. Run source ~/.espressif/tools/activate_idf_v6.0.2.sh to activate the IDF environment
    4. Run idf.py build to build your project

  8. Surge opção "Show Dashboard" que confirma a instalação da versão v6.0.2 em /Users/fernandopassold/.espressif/v6.0.2/esp-idf.

  9. E aparece opção para "Install New Version" (não selecionada).

  10. App encerrado.
