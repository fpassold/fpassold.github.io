Recursos disponíveis

  • Placa compatível com: ESP32-WROOM-32.

  • Provavelmente será usada a placa 👉 ESP32-DevKitC V4, que contêm o chip ESP32-D0WD, compatível com ESP32-WROOM-32UE Esta placa possui um conector para antena externa WiFi e possui dois canais DAC de 8 bits (GPIO25/GPIO26). Possui 19 pinos de cada lado.

  • Ou identificar placa iniciando em ESP32-DevKitC ou Seletor de Produtos ESP.

    • Datasheeet do chip ESP32-WROOM-32E/-32UE/-32UE.

      • Na variação 32UE, existe um conector para antenas externas de WiFi, mas placa já conta com Bluetooth.

    • Informações da placa ESP32-DevKitC V4 (barramento I/O, botões).

IDEs para programação?

  • A Espressif recomenda instalar sua adaptação para o Eclipse CDT, ou Espressif-IDE (ver opções de Download, conforme seu sistema operacional); Note que depois ainda se faz necessário instalar ferramentas extras.
  • Mas você pode optar pelo 👉 Arduino IDE, que parece ser a forma mais simples e imediata de começar a trabalhar com esta placa. Recomenda-se seguir as instruções de: Installing using Arduino IDE;
  • Você pode usar o VS Code instalando (e configurando) a extensão: ESP-IDF Extension for VS Code e eventualmente mais a extensão PlatformIO IDE. Ver exemplo para versão de 2024. A configuração pode resultar bastante complexa e complicada…
  • Ou usar apenas o terminal + editor de textos comum.

Atividades Práticas

  • Primeiro Teste Testar uma placa ESP32 devkit, embarcando um simples programa: conforme se pressiona o botão “Boot” da placa ESP32, alternar entre piscar (à 2 Hz) ou manter apagado o led (eventualmente) presente na placa, além de exibir mensagens no terminal serial. Logo após o início da execução (seção setup() no Arduino IDE) deve ser impressa a mensagem "Alo, estou aqui". Depois (na seção loop() no Arduino IDE), a cada segundo fazer aparecer no terminal serial a mensagem "Placa ativa à XX segundos", onde XX equivalente ao tempo que a placa já está ligada e plugada no terminal serial. A idéia é usar rescursos já disponíveis na placa e tasks do FreeRTOS.
