Instalação dos pacotes Espressif ESP-IDF usando Arduíno IDE

Atenção: O EIM (Espressif Installation Manager) é apenas um assistente para instalação de ferramentas ESP-IDF e compilação usando terminal ou outras IDEs. Ele é necessário mas não é nenhuma IDE de programação.

Se você quer apenas programar o ESP32 em paz sem depender de ferramentas especias (brew, outras) e sem usar o VS Code, a sua melhor rota de fuga é a Arduino IDE.

Muitas pessoas associam o Arduino apenas a projetos básicos, mas a realidade pode ser outra:

  1. Instalação em 2 cliques: Você baixa o instalador tradicional do site do Arduino e pronto. Ele é 100% independente do seu sistema.
  2. Gerenciador de Placas Isolado: Dentro da Arduino IDE, você vai em Configurações, cola o link da Espressif e instala o pacote do ESP32. Ele baixa os compiladores pré-compilados e binários específicos dentro de uma pasta isolada. (Zero dependência de outras ferramentas, zero reclamação de Python do sistema).
  3. Compila e Grava Direto: Ele reconhece a porta USB e faz o upload sem precisar configurar ferramentas extras.
  4. Suporte ao código oficial: Você pode programar usando a própria linguagem do Arduino (C++) ou, se preferir, pode chamar funções nativas do ESP-IDF diretamente no código, pois o core do ESP32 para Arduino é construído em cima do ESP-IDF.

O conselho de um colega desenvolvedor: Apague tudo o que você tentou instalar até agora para limpar o computador. Se o seu objetivo é ver o código rodando na placa sem travar uma batalha contra o macOS Sequoia, instale a Arduino IDE. É o caminho com menos resistência para o seu cenário atual.

Identificação da Placa

Os dados observáveis da placa:

  • Serigrafia no verso da placa: "ESP32_Devkitc_v4";
  • Na parte metálica frontal aparece: "Model ESP32-32U, ESP32-32X".

Com base nestas marcações, esta placa é oficialmente uma ESP32-DevKitC V4 equipada com o módulo ESP-WROOM-32U.

A indicação ESP32-32U na blindagem metálica confirma que o seu módulo é a versão 32U, que possui as mesmas especificações internas do ESP32 padrão, mas traz um conector IPEX (U.FL) para antena externa em vez da antena desenhada na própria placa.

Para selecionar e configurar essa versão corretamente na Arduino IDE, siga as instruções abaixo:

Seleção da Placa Correta

  1. Acesse o menu Ferramentas (Tools) > Placa (Board) > ESP32 Arduino.

  2. Procure e selecione a opção

    ESP32 Dev Module

    (essa é a opção genérica mais estável e recomendada para a linha DevKitC).

    • Alternativa: Em versões mais recentes do pacote da Espressif, você também pode encontrar o nome exato ESP32-WROOM-32D/32U DevKitC ou simplesmente ESP32-DevKitC. Ambas as opções funcionam perfeitamente.

Parâmetros adicionais de hardware

Após selecionar a placa, certifique-se de manter as seguintes propriedades padrão no menu Ferramentas:

  • Flash Frequency: 80MHz
  • Partition Scheme: Default 4MB with spiffs (o módulo 32U padrão possui 4MB de memória Flash).
  • Upload Speed: 921600 (se apresentar erros para carregar o código, reduza para 115200). [3]

Se encontrar alguma mensagem de erro ao tentar transferir o código, me avise:

  • A gravação travou em "Connecting..."?
  • A IDE informou que não encontrou a porta COM?
