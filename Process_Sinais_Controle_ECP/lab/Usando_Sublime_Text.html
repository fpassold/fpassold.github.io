Intro

Abordagem mais rápida e limpa se você busca máxima velocidade e zero interfaces pesadas. Esta combinação usa o terminal para o trabalho pesado e o Sublime apenas para edição de texto.

Passo 1: Abrir o projeto no Sublime Text

  1. Abra o Sublime Text.
  2. Vá em File > Open Folder e selecione a pasta do seu código exemplo.
  3. Pronto, o Sublime está configurado para editar seus arquivos .c, .cpp ou .h.

Passo 2: Abrir o terminal integrado da Espressif

Para compilar, você deve usar o terminal que já possui as variáveis de ambiente do ESP32 carregadas:

  • Windows: Abra o menu iniciar e busque por ESP-IDF PowerShell ou ESP-IDF Command Prompt (atalhos criados pela instalação gráfica que você fez). Para encontrar o atalho no Windows.
  • Linux/macOS: Abra o seu terminal comum e execute o comando de exportação (exemplo padrão: source ~/esp/esp-idf/export.sh).

Passo 3: Comandos de Terminal para controlar a placa

No terminal que você acabou de abrir, navegue até a pasta do seu projeto exemplo (cd caminho/da/pasta) e use os três comandos principais da ferramenta idf.py:

  • Definir a placa (Target):
xxxxxxxxxx
% idf.py set-target esp32
  • Compilar o projeto:
xxxxxxxxxx
% idf.py build
  • Gravar no ESP32 e abrir o Monitor Serial (Tudo junto):
xxxxxxxxxx
% idf.py -p COMX flash monitor

Exemplo de comando de flash no macOS: % idf.py -p /dev/cu.usbserial-1410 flash monitor

 

Obs.: Substitua COMX pela porta real do seu ESP32, como COM3 no Windows ou /dev/ttyUSB0 no Linux. O comando monitor mostra os printf do código em tempo real. Para sair do monitor, pressione Ctrl + ]).

Resumo (Sublime + Terminal)

Se você optar pelo método rápido, a receita de bolo na aula será:

  1. Montar a estrutura de pastas e colar os dois arquivos CMakeLists.txt explicados acima.
  2. Abrir o terminal (com o ambiente ESP-IDF carregado).
  3. Navegar até a pasta raiz: cd caminho/de/MeuProjeto
  4. Rodar o comando para compilar: idf.py build
  5. Descobrir a porta (usando os comandos acima) e rodar: idf.py -p PORTA flash monitor
